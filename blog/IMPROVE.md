# 블로그 스킨 개선 사항 리스트

## 1. 비로그인 댓글 프로필을 환세 시리즈 캐릭터 얼굴로
로그인하지 않고 쓴 댓글은 티스토리 기본 썸네일(`.tt-thumbnail` 의 인라인
`background-image` 에 `tistory_admin/static/manage/images/r3/default_S.png`)로 나온다.
이걸 환세 시리즈 캐릭터 얼굴 이미지로 바꾼다. 44×44(2배 88×88) 얼굴 이미지 세트가 필요하다.
같은 닉네임은 항상 같은 얼굴이 나오도록 닉네임 기준으로 고르는 스크립트를 `skin.html` 에 넣는다.

## 2. 히어로 캐릭터 표정·의상 이스터에그
hover 시 캐릭터의 다른 표정이나 의상 그림으로 바꿔 보여 준다. 새 그림이 필요하다.

## 3. 새 작품이 생기면 작품 칩 추가
`skin.html` 의 `.area_titlenav` 는 하드코딩이다. 새 작품 글을 시작하면
`<a href="/tag/새작품">새작품</a>` 한 줄을 추가한다.
