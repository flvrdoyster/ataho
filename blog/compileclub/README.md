## 설정·뒷이야기로 건진 것

- **페니 = 페톰의 이전 이름**으로 보임
  - 38호 만화: 「ペニー ♂ 140歳 そう、例の魔法使い」 (♂는 스마슈와 같은 기호, 키리는 ♀)
  - 51호 광고: 페톰 자리(초록 머리)에 「ペニー」
  - 한글화 GUIDE: 페톰 「외견은 젊지만 실제론 140세」
  - 지하판 30호: 페톰은 디스크 사가로 데뷔, 원래 TRPG 캐릭터였고 처음엔 여자
- **스마슈**: 처음 설정은 「변태 개」, 우여곡절 끝에 「화장실이 가깝다」도 추가 (51호 광고)
- **키리**: 원형은 「三代目九郎判官義経・霧」 (79호 캐릭터 인터뷰)
- **실라**: 희담 신캐릭터이자 DS의 환세풍광전에도 등장 (51호 광고)
- **디스크 사가**: DS98에 실린 연재 게임. 환세 시리즈의 원류 (66·67호 DS 역사 연재, 42호 p10)
- **거꾸로 쓴 타이틀** 「譚喜世幻 / III agaS csiD」 (42호 p10 대화에 언급)
- **몬스터**: 케이브캣·위치(45호), 대해수·테리진·게(42호)는 게임 텍스트에 없음. 개발 중 이름이거나 빠진 것
