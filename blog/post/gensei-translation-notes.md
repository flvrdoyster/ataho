# 환세 시리즈 지명 표기·원문 확인 메모

블로그에 지명을 옮길 때 걸릴 만한 항목과, 정리 중 눈에 띈 번역 점검 포인트다. 수정 제안이 아니라 기록이다.

| 항목 | 내용 | 위치 |
| --- | --- | --- |
| 江畔の町 vs 湖畔の町 | 게임 원문은 江畔(강반). atwiki 희담 공략은 湖畔으로 잘못 적음 | 희담 `SC1A #31` |
| 町長 → 촌장 | 청류마을·바다마을 모두 원문 町長, 번역 촌장 | 희담 `SC3A #12`, 풍광전 `STAGE2 #95` |
| 번역에서 빠진 지명 | 「北の清流の町」→「청류마을」('북쪽' 생략), 봉쇄된산→「저 산」, 「地獄の町」→「지옥」, 「隠し扉の街か…」→「비밀 문이라…」 | 희담 `SC1A #75`, `SC4A #22`, `SC5B #22`, 쾌도전 #3 L556 |
| 거꾸로 된 성 | '거꾸로 된 성'과 '거꾸로된 성'이 혼재 | 희담 `SC1B #64`, `SC2G #8` |
| 블레이드・플라즈마 | 풍광전 화자 태그는 '브레이드', GUIDE 확정은 '블레이드' | 풍광전 `STAGE5` |
| 地獄平野 vs 地獄原 | GUIDE 9-4는 地獄平野, 포물장 원문은 地獄原 | 포물장 #3 |
| 温泉街 vs 湯の町 | GUIDE 9-4는 温泉街→온천가, 원문은 湯の町・温泉の町, 번역은 '온천마을' | 포물장 #30, #40 |
| 동쪽나라 / 서쪽 나라 | 띄어쓰기 혼재. この国이 '이 영지'와 '이 나라'로 갈림 | 포물장 #1, #5 |
| キツネの里へやってくる | '여우마을에서 오는'으로 번역(원문은 '여우마을에 오는') | 포물장 #47 |
| ５合め付近 | '중간쯤'으로 의역. 후지산 등산로 구간을 가리키는 '5합목' 표현이 빠짐 | 포물장 #53 |
| 堺のトンネル | 매뉴얼·대사 모두 후리가나가 없어 읽는 법 확인 불가. 번역은 뜻을 살린 '경계터널' | 풍광전 매뉴얼 |

- 대사 위치 표기: 희담·풍광전은 `파일 #인덱스`, 쾌도전·포물장은 `#청크 L줄`이다.
