# 대시보드 개선 사항 리스트

남은 과제만 정리. 완료되어 제외된 항목은 git 히스토리 참조.

## 1. GA와의 차별점이 얇다 — 가장 큰 과제
현재 GA4 화면과 실질적으로 다른 건 셋뿐:
호스트 3개(atah.io / pc98 / suiko) 분리, 경로를 코너 이름으로 묶기,
로컬(localhost·사설 IP) 방문 제외. 나머지는 GA가 이미 하는 일의 재탕이다.

갈라지려면 **GA가 구조적으로 알 수 없는 것**을 넣어야 한다. GA는 이 레포를
모른다 — 언제 무엇을 만들었는지, `/sweep`이 미니게임인지 알 방법이 없다.
후보(검토만 하고 보류):
- **커밋 × 방문 겹쳐 보기** — 추세선에 그날의 커밋을 표시해 "뭘 만들었더니
  사람이 어떻게 움직였나"를 보여준다. `git log`만 있으면 되고 구현이 가볍다.
- **평소와 다른 날만 짚기** — 28일 분포에서 벗어난 날·유입원만 문장으로.
  지금의 인사이트 문장은 1위/비중 나열이라 판단이 없다.
- **미니게임 이벤트 계측** — 시작·클리어·이탈을 GA4 커스텀 이벤트로 심고
  게임별 완주율을 본다. 가장 값지지만 각 게임에 코드 삽입이 필요하다.

## 2. 레이아웃 겹침 — 원인 미확정
카드 테두리를 걷어내고 여백 구조로 바꾸면서, 표 8곳에 `overflow-x: auto`
래퍼와 그리드 칸 `min-width: 0`, 캔버스·SVG `max-width: 100%`를 넣어 두었다.
다만 겹침의 실제 원인은 확인하지 못했다 — 작업 당시 브라우저로 열어 볼
수단이 없어 "표가 칸을 넘쳐 옆 구획을 덮는다"는 가설로만 막아 둔 상태다.
다시 겹치면 어느 구획인지부터 확인할 것.
